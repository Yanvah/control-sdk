# Code of Conduct

People of all backgrounds and experience levels are welcome in this project. Treat participants with respect, explain technical disagreements, and focus criticism on ideas and code. Respect boundaries, privacy, and requests to stop unwanted contact.

Harassment, discriminatory language, threats, sexual harassment, deliberate disruption, and publishing another person's private information are not acceptable. These expectations apply to repository issues, pull requests, discussions, and other spaces where someone represents the project.

Maintainers may edit or remove harmful content, close discussions, warn participants, or restrict participation. They should explain moderation decisions when doing so does not expose confidential information, and apply these standards consistently. Serious or repeated misconduct may result in a permanent ban.

For conduct concerns, use GitHub's [Report content or Report abuse controls](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) on the relevant content or account. For project moderation, you may open an issue asking a maintainer for a private contact method without including personal details. Do not publish a report containing someone else's private information. If a maintainer is involved, use GitHub's reporting controls rather than directing the report to that person. Vulnerability reports use [SECURITY.md](./SECURITY.md).
